# Documentación del Sistema

## Archivos disponibles

- **manual_usuario.md** — Manual de usuario completo con pruebas funcionales (28 casos de prueba)
- **guion_video_tutorial.md** — Guión de 11 escenas (~22 min) para grabar el video tutorial
- **capturas/** — Carpeta para guardar las capturas de pantalla del sistema

## Cómo tomar capturas de pantalla

- `Win + Shift + S` → Recorte rápido al portapapeles
- `Win + G` → Xbox Game Bar (capturas y video)
- Guardar en: `docs/capturas/`
